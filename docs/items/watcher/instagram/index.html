Thirteen skills that run an Instagram account, packaged from Jake Schincariol's MIT-licensed [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill).

  • Reels: hooks from 26 formulas, scored before you film.
  • Captions: shows what the feed shows before "… more".
  • Carousels, stories, comments, replies, DMs and repurposing.
  • Profile audit: a score out of 100 with rewrites.
  • Weekly plan and a viral-reel finder for your niche.
  • Humanizer: strips slop vocabulary and watermark characters, then checks the draft.

Nothing is posted: these skills write, you post. Skills with scripts also add a tools extension, which goes through its own approval.
