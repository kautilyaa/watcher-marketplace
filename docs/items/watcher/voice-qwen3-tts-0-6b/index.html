Alibaba Qwen's Qwen3-TTS 12Hz 0.6B CustomVoice as a voice for calls and reading aloud, with its two English speakers.

  • Large: 2.5 GB of model files (model and speech tokenizer weights, configs, tokenizer) plus PyTorch and the qwen-tts 0.1.1 packages: about 0.3 GB on macOS, about 4.4 GB on Linux x86_64 (PyTorch from PyPI brings NVIDIA CUDA libraries).
  • May be slow without a GPU: Qwen documents it on CUDA only; its speed on a CPU or Apple silicon is not measured. Prefer Phonon-31M or Pocket TTS on a laptop.
  • Voices: Aiden (American, male; the default) and Ryan (male). No speed control.
  • Packages: qwen-tts 0.1.1 pins transformers 4.57.3 and accelerate 1.12.0; this lock keeps torch/torchaudio 2.10 and librosa 0.11, the releases current when qwen-tts 0.1.1 shipped. sox has no wheel and installs from source.
  • Licence: weights and code Apache-2.0.

How it installs. This item holds no weights or code: it pins each Hugging Face file to a commit with its size and SHA-256 (or git blob id), and every Python package to an exact version with its hashes. After an admin approves the install, Watcher's local voice service downloads the pinned files from huggingface.co, checks each one, installs the packages into a venv of their own (uv pip install --require-hashes --no-deps), and runs the engine offline in a separate process. It needs the local voice service (RWCTL_LOCAL_SETUP=1); Kokoro stays the default and takes over whenever this voice isn't ready. Uninstalling deletes the files and the venv.
